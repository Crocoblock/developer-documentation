# What Are WordPress Hooks and Filters

WordPress hooks and filters are mechanisms that allow you to extend and modify WordPress functionality without directly altering the core system code. They enable developers to create custom applications, plugins, and themes that can interact with the core WordPress system.

The plugin uses hooks both for rendering content on the frontend and for actions within the admin panel.

There is also the option to hook into JavaScript events on the frontend, which allows you to track the lifecycle of each popup.
